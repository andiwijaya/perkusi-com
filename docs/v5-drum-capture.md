# Bounded drum live-pad capture

AG1 adds the two existing Studio kits Ruang and Arus, explicitly labelled original synthetic drums (not acoustic recordings). Each eight-pad/native48k selection uses the complete pinned existing kit, with immutable hashes and source recipe/CC0 records. No asset bytes, recipe, tuning, sample rate or source trims change. Only the trusted registry accepts the exact existing /internal/studio-kits/audio paths. Capture factory also requires exact same-kit descriptors/tuple, so arbitrary imported bank data cannot acquire this capability.

The existing root InstrumentSampleCache/Transport/AudioMemory and stereo monitor/capture capability are reused. Native mono one-shots duplicate into the explicit stereo bus. Studio's shared createOneShotVoice envelope is retained:0.6ms attack and4ms end fade with original gainTrim. Physical release removes its token and lets the tail finish; last-owner damping for Saron/Slenthem remains unchanged. Closed hi-hat explicitly chokes only open hats that started before that musical instant, using the existing4ms owned-envelope fade; future scheduling order is respected. Other pads/retriggers overlap naturally. No voice stealing: four live/ending/scheduled voices and16 physical tokens maximum; a refused hit changes no existing tail/claim/token. Pins survive until actual native onended or confirmed context closure.

Root admission reserves five producer voices (four plus topology carrier), separately one capture replay,57344bytes producer/node/token allowance, all native cache allocations and existing full stereo capture reservations. Peak uses4*max(decodedPeak*gainTrim) plus conservative overlapping monitor/replay/foreign tracks and current mixer/pan/FX. Prepare, runtime strikes and mixer changes all use root admission. Monitoring follows existing selected-track gain/pan/mute/solo and master once; capture retains pre-mixer original. Stop/blur/hidden explicitly silence with controlled fades; Cancel, partial takes, provenance, adoption/durable storage, portable and final WAV reuse existing lifecycle. No direct destination monitor.

UI has8 keyboard/pointer/accessibility pads A S D F G H J K, descriptive ID/EN labels, natural-tail/choke/cap guidance and44px+ targets. A next-source selection cannot play an old prepared source; source choice is locked while active voice/record/review owns it. Gamelan retains two notes and release-to-damp semantics.

Acceptance is bounded to measured headless/muted native48k cases in the separate AG evidence folder. Automated events are not physical keyboard/touch/output/listening validation. Original Chrome strict-clock and independent smoke failures remain FAIL/causeUNVERIFIED. Full V5, microphone, other source families, broad rate/bar/device/long-session qualification and release remain HOLD.

AG2 corrects unsaved full/partial take WAV provenance: read descriptors from the retained capture record and reconstruct the immutable same-kit assignment, rather than using the Gamelan fallback or whichever producer is currently selected. Saved/adopted provenance and all audio/DSP remain unchanged. Regression covers both kits, full/partial status, misleading current producer and every PCM/source hash in the Float32 WAV. Native partial repair proof is separate from the retained AG1 failure and original healthy captures.
