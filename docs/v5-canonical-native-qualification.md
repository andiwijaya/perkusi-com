# Q1c.b bounded native qualification contract

This is an isolated candidate for independent review. The actual main Rhythm Studio remains the combined composition/master/Pattern Chain destination. No active route, UI, feedback, storage or production audio consumer uses this candidate. Q1c.a's sealed snapshot remains immutable; its dense-endpoint source defect is repaired in the current tree with bounded iteration, not a raised engine stack limit.

`prepareCanonicalScore` privately validates through the canonical timeline and accepts a trusted source provider, shared `AudioMemory`, registry, exact44.1/48kHz rate, explicit finite command and exact AudioBuffer factory. Provider `describe` is synchronous and must not decode. Its geometry/trim/hash snapshot is checked before the first `load`; complete source/encoded/decode/view/temporary-hash/group-output/future-native allowances reserve before loading. A rejected provider owns its partial load; a successful load returns one releasable immutable loan. Actual decoded geometry, finite values and raw PCM hashes are checked before publication. Shipped encoded identities require the trusted provider's verified receipt and matching expected native registry hash. The production provider/legacy-owner bridge is not implemented or qualified by the QA provider.

The QA provider is explicitly `purpose:qa`, creates only rational deterministic multi-component RAM waveforms and never returns production sample hashes as their identity. Raw recording hashes match that separate QA capture, including its exact period and signed alignment. Its metadata catalog hash-authoring scratch is separately charged before the preparation phase. No retained PCM/WAV or production sound assets are added. Quality/listening/culture/physical devices remain separate gates; no new claim is made for them.

Native source data is shared by content/source key; mutable metadata callers and command objects are privately captured. Native mix scopes and tuning consent are preserved. Schemas0-4 apply their project-bound master inside the source group and use a unity outer bus; schema5 preserves local/parent source master and independent outer gain/limiter. Zero, custom and maximum original masters are not replaced by a default. No clip/source period, raw alignment hash or source offset is rewritten.

`canonical-dynamic-render` compiles the actual pattern sequence into a prepared composition bus. It preserves the six pattern-owned phrase controls, group-local solo/mute, global percussion/Bilah scope, source/variant/processing identity, five-second anchors, linear4ms entry/exit releases, established exponential4ms mixer targets and role chokes. Same-source continuous placements on one bus can share one run across different placement IDs; explicit restart creates another run. Uniform continuous runs compare bit-for-bit with independently parsed legacy cycle states, including the terminal natural/release tail. Finite original compositions retain the old body/fade/curve policy. Internal preparation contributions still pass the16-voice limit; a prerender cannot bypass it.

For an interrupted exponential target, the new target starts from the last rendered sample. An independently captured native constant-source probe found and closed the previous one-sample anchor error. Native engines also settle/prune sufficiently small residuals at render-quantum boundaries, while the frame kernel retains the analytic residual. Report transient and full-envelope error separately. The bounded probe requires <=4e-6 transient coefficient error through six time constants and <=4e-5 over the complete8192-frame coefficient trace. These are **gain-coefficient** limits, not PCM limits; report their measured values and engine rather than claiming bit equality.

Verified complete recording periods coalesce into a persistent reader only for matching bus, raw hash, phase and contiguous complete windows. Every original placement ID remains recorded. Positive/negative circular advances read unchanged PCM. Nonzero offsets, wrong rates and incompatible periods refuse with their explicit old playback issue. Root Loop remains an explicit finite4/8-bar window; no new live wrap is inferred from display length.

Prepared plans use a private brand. Live/WAV adapters retain the source owner; disposing the caller's score prevents new consumers but releases its loans only after all current consumers complete. A failure releases only its own work. Frozen event/spec/placement records do not grant imported JSON access to native capabilities. Shared AudioBuffers follow the trusted immutable-loan contract; this is not a defensive copy of arbitrary caller-mutated PCM.

`canonicalVoiceAdmission` retains the16-owner /0.95 guard with0.75s lookahead and0.45s callback grace, including outer EQ/pan/gain/solo and outgoing tails. `canonical-voice-budget` adds a shared private pool keyed by the workspace AudioMemory, so separate new native live/offline contexts compete for the same16 pending/actual owners and conservative peak allowance. Legacy active owners must register their real owners before future integration; this candidate does not silently discover/control the current legacy preview/context. Pending owner tickets and complete graph/node allocation scopes are charged to the same64MiB pool before native allocations. Child helpers cannot grow/release the parent's reservation.

The direct native backend keeps a stable graph for programmes with at most16 total readers, retaining ended nodes and pins through the programme/EQ tail until actual ended or awaited context close. Longer programmes now prepare a private complete post-EQ/post-limiter Float32 programme print, after the ORIGINAL programme passes concurrent16-voice and0.95 admission. A single native AudioWorklet reader plays that print without topology changes; its complete clone/node allowance is charged before construction. Native offline playback reads bounded32768-frame windows, avoiding another full input copy. Full natural/release/EQ tails and original master scopes are retained. This is finite preparation, not qualified interactive replacement or unlimited duration: a programme that cannot fit the unchanged64MiB pool refuses. Pending native owners in other registered contexts remain counted.

The session factory must construct an exclusively owned fresh context. It never accepts an ambient preview context or microphone/device input. Same-context pause/resume preserves the AudioContext frame origin; wall time does not advance a suspended plan. EQ seeking requires an explicitly prepared complete-history print (`prepareCanonicalPlayback`); absent that preparation, it refuses `canonicalPlaybackNotPrepared`. Seeking selects an offset into the evaluated print, preserving filter history instead of resetting IIR state. The WAV programme/calibration authority stays the original prepared programme. `canonicalScoreFrame` publishes anchors from the actual rendered merged run, together with expanded placement, original placement, occurrence and pattern IDs; the old logical `canonicalTimelineAt` is not the audio feedback authority.

The raw interrupted-target characterization is engine-dependent: Chromium/Edge hold the previous rendered sample, while Firefox's implicit target uses the continuously evaluated boundary value. Raw Firefox probes remain FAILED at both rates in the sealed partial checkpoint. `canonical-native-ramp.js` explicitly anchors each target. The separate successor Firefox owned-anchor probes now PASS at both rates, complementing the four prior Chrome/Edge cases. This does not relabel the raw failures or qualify interactive replacement.

The WAV adapter uses the established two-pass programme meter/calibration, final safety curve and streamed Float32 WAV encoder. It does not invent another normalization/limiter. Native post-programme capture is compared to that encoded PCM, with independent original-legacy CPU tests retained as the migration oracle. Final rate/channels/frames/RIFF/data sizes and whole encoded hashes are recorded. Native low-level DSP differs slightly in scalar/curve reduction: end-to-end tests require <=3e-6 absolute and <=1e-6 RMS PCM error, plus exact frame endpoints and a nonzero expected tail. Exact comparisons are identified separately; approximate native comparisons are never called byte-identical. The initial stricter3e-7 RMS pilot and the actual mixed-graph failure remain recorded.

Silent native QA uses fresh browser profiles and a downstream AudioWorklet tap whose output and terminal gain are zero. It does not change source/mix graph behavior to manufacture passing data. A real400ms main-thread stall and pause/resume are exercised on the mixed profile. No microphone, device enumeration, database, localStorage or owner preview action is permitted. Cases at both rates in available Chromium/Edge/Firefox are recorded separately; failed/unavailable cells remain gaps.

Remaining integration work: independent review of the successor stable-print and prepared-feedback implementation; production provider/provenance and actual legacy-owner bridge; atomic main-Studio controller and edit invalidation; native fault cases beyond the bounded suite; opt-in main-Studio UI smoke and later durable packaging/continuation. The successor report distinguishes exact17/20-reader reproductions, native journeys, EQ-history tests and remaining gaps. Full Q1c/UI/production acceptance, Product V6 and publication remain held.
