## Integration

InstrumentSession composes the existing AudioEngine: its AudioContext creation/resume/master/output graph and Transport are reused. One scene-wide ExtensionOwners instrument resource stops the active voice Set; there is one export cancellation resource per export job. Voice history is not retained in the owner adapter. Sources keep their independent pin until onended. Suspended contexts are closed; pins are forced down only after close resolves. Focus readiness commits only after every selected recorded note is loaded, and switching stops old voices before releasing their focus pins. No silent voice stealing:16voices and conservative0.95 headroom bounds refuse visibly.

## Global memory and native ownership

AudioMemory owns one64MiB monotonic ResourceBudget for cache loads/retained PCM, live node allowances, owned context allowances, renderer accumulators/native blocks, WAV staging and Blob copy. Cache optional memoryPolicy reserves encoded+max(encoded,decoded) before fetch; it shrinks only after actual decode and transfers the retained reservation with the cache entry. Eviction/disposal release global reservation only after scoped pins permit it. Shared policy provides a global four-decode gate across contexts, in addition to accepted per-context queue/native bounds. Its accepted standalone default behavior remains unchanged.

New lease.retain() creates another owned ready scope without the loading AbortSignal; it prevents a canceled loading consumer from releasing the actual source used by a voice/render. Export uses a separate cache facade on the live context, so closing/disposal of the scene facade cannot erase its foreign render pin. trim() evicts only unpinned settled entries. All cache histories remain the accepted monotonic/no-reuse policy. Context512KiB and voice4KiB allowances are declared engineering allowances, not measured browser DSP/OS cost. The pool excludes general JavaScript/DOM/schema objects and browser/network/GC overhead; actual process working sets are measured separately. This is not a64MiB RSS promise.

## Events, files and render

Schema4 InstrumentProject retains a complete empty legacy composition plus exact origin text and explicit bank/version/sample/tick/strike/damp/velocity events, PPQ960000. Recording uses shared AudioContext time and a frame-aligned origin, max32seconds per segment, append behavior, and reserves event capacity for stop/damp. Tempo is locked while events exist. Imported IDs cannot corrupt the private event issuer; size admission precedes parsing. Empty legacy projects can migrate through accepted helpers. Active legacy composition layers are explicitly refused in this slice, retaining the current take, because the actual Studio bridge is a subsequent reviewed slice. Download/import current schema4 is supported; no storage-success or Studio-playability claim.

Replay preloads all referenced sounds and checks headroom/voice admission before clock start. Pause/cancel/generation guards prevent stale loads or replay from rearming. Recording/replay/focus ownership is distinct from export. Import/clear and interruption preserve current project semantics and do not silently overwrite a failed import.

Offline WAV uses65536-frame blocks and renders each sounding sample group in its own native OfflineAudioContext. The accumulator sums full source segments with exact offset/frame/damp continuation; source files are never shortened. The same live articulation contract applies to each segment. Encode stereoPCM16 at the actual44.1k/48k profile, with finite/peak validation, up to90seconds including full tails. Both complete PCM staging and Blob copy are admitted before allocation. Actual native render is awaited after cancellation before its output/sample reservation is released. Insufficient memory while playback pins exist refuses without stopping them; explicit Pause, release audio & export closes the live scene and lazily decodes only recorded sounds. URLs/output reservations are released explicitly or on disposal. This bounded export is not a complete128-bar V4 renderer acceptance.
