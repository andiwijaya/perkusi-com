## Delivery cost and compatibility policy

The complete FLAC corpus is 244,977,383 bytes versus canonical PCM 479,867,000 bytes. This is whole-package storage, not initial page download. Accepted calibrated desktop 4 Mbps/150 ms results are approximately 17.9 seconds for default Saron and 39.3 seconds for the worst Slenthem focus, versus 32.2 seconds for default PCM. Complete source-decay geometry and decoded Float32 memory stay unchanged. The final code does not raise memory caps or deadlines, omit instruments/tails or preload both banks. Slow mobile/WAN/CDN behavior still needs actual observation; UI remains useful before enabling audio and exposes localized loading/error/retry states.

Chrome/Edge/Firefox native exactness is accepted. Safari/iOS and other target-device FLAC decode support are unverified. The concrete proposed initial support policy is: offer Gamelan Preview only on separately verified engines; expose existing per-focus decode/load error/retry; keep legacy Beatbox/Studio available; retain PCM operator rollback if a confirmed target decode defect appears. Do not promise automatic runtime downgrade, silent transcoding or Safari support. Confirm this support/rollback policy before public Preview entry promotion. Codec selection itself is already resolved and requires no renewed owner choice.
