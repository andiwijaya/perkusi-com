# Local V5 microphone monitoring and loop position compensation

Monitoring starts off on every microphone activation. The user must explicitly confirm low-volume wired headphones before enabling it. The root owner reserves the combined mix/capture headroom before connecting a silent stereo monitor route. The microphone meter worklet changes monitor state at a future native frame and returns a receipt; disabling keeps the old reservation until that receipt. Selected-track Stop also releases the mic after capture closes. Stop Mic remains available during a pending operation.

Missing worker-close acknowledgement does not release its ledger allowance. An actual context-closed event can settle a pending mic close. If the close deadline already failed, root recovery retries that failed producer only after the context is confirmed closed. A timer is never evidence of worker termination.

The monitor uses fixed gain 0.25 and a whole-quantum safe-input gate at peak 0.5 (maximum admitted monitor peak 0.125). Unsupported/changing topology or nonfinite input latches silence. Overrange input mutes that monitor quantum; it does not clamp, normalize or modify capture input. Interval meters and cumulative clipped-sample counts continue to describe the original input. This cannot prevent acoustic feedback in an arbitrary physical room; hardware/listening validation is still open.

Complete fixed-bar recorded loops may have optional `phaseAlignment` metadata: `{version:1, mode:"circular-period", sourceSHA256, advanceFrames}`. It is bound to the original recording hash, native rate and complete 1/2/4/8-bar period, with signed integer advance bounded by ±250 ms and strictly less than a period. Positive values advance late material by changing the reader position; negative values delay it. The reader wraps within the same recorded period. No original PCM, hash, capture frame count, ordinary offset or clip duration changes. Outside-window audio cannot be recovered. Unknown/malformed versions, event clips, nonloops, generic offsets, hash mismatch and wrong period/rate fail closed.

Each layer is adjusted independently. Preview plays the whole mix for four bars using a candidate manifest without saving. Ordinary Play loads the saved manifest again. Save position persists through the existing durable project/history transaction; Reset removes the optional field. Undo/redo and portable export retain the original raw asset. Final WAV metadata includes the exact project alignment. Continuous native readers, planned native event readers, the finite worklet and portable/final-WAV readers apply the same circular position. This is manual compensation; no automatic hardware measurement, device profile, round-trip estimate or ≤25 ms claim is supplied.

It remains failed as an overall acquisition. A separate live context supplies full finite coverage/closed receipts and the corrected generated-stream monitoring acquisition. All cases use generated QA audio, not real microphone permission or physical listening. The observer's behavior after its completed transfer was not instrumented; only its original completed packet and final context closure qualify.
